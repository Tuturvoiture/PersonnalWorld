# Rapport d’exploration — PersonnalWorld

## 1. Project overview

**PersonnalWorld** (`fr.galsaxx`, id `personnalworld`) est un mod Minecraft qui donne à chaque joueur une **dimension personnelle** (île NBT dans un void flat), accessible via un objet « bâton du monde perso », avec sauvegarde de position de retour.

| Élément | Valeur |
|--------|--------|
| Version mod | **1.2.2** (`gradle.properties`) — README dit encore « V1 » |
| Minecraft | **1.21.1** (Stonecutter : une seule version) |
| Loaders | **Fabric** (fonctionnel) + **NeoForge** (entrypoint stub) |
| Multi-loader | **Architectury** + **Stonecutter** + Loom |
| Langage | **Java 21** |
| Licence | **LGPL-3.0-or-later** |
| Dépendance clé | **DimLib** 1.1.0+mc1.21.1 (JAR local dans `libs/`) |

Branche actuelle : `feature/multi-version-multi-loader` (commits récents : scaffold Stonecutter / modules Architectury).

## 3. Features implemented

### Item & téléportation
- Item `personnalworld:personnal_world_item` — `PersonnalWorldMod.java`, `PersonnalWorldItem.java`
- Clic-droit : crée/téléporte vers `personnalworld:perso_` ou retour à la position sauvée
- Cooldown 40 ticks ; spawn hardcodé `(24, 68, 17)`

### Dimensions dynamiques (DimLib)
- `PersonnalWorldUtil.ensurePersonalWorld` — preset `minecraft:the_void`, `DimensionAPI.addDimensionDynamically`
- Init one-shot via `PersistentState` (`personnalworld_init`) : clear plateforme + île

### Génération d’île
- `IslandGenerator.java` — place structure `minecraft:ile_1` (après copie NBT)
- Fallback plateforme pierre 3×3 si NBT absent

### Copie de structures
- `StructureCopier.run` au `SERVER_STARTED` — copie `data/personnalworld/structures/*.nbt` → `generated/minecraft/structures/`

### Persistance position
- Mixin `PlayerEntityMixin` + interface `ReturnPositionSaver` — NBT `pw_returnPosition`

### Commande
- `/returnworld` — `ReturnWorldCommand.java` (restriction monde perso)

### Recette crafting
- `fabric/.../recipe/personnal_world_item1.json` — sticks + grass_block

### Assets / i18n
- Modèle Blockbench 3D, textures, **10 langues** (`en_us`, `fr_fr`, `de_de`, …)
- Groupe créatif Tools

### Non implémenté (malgré scaffold)
- Pas de blocs custom, biomes, entités, UI, networking, configs
- Invitations amis : dossier `src/.../invite` **vide**
- NeoForge : aucune logique dimension

## Étape 1 — Mise en place de Stonecutter (multi-version)

## Étape 2 — Mise en place d'Architectury (multi-loader)

4. Pour les parties dépendant du loader (enregistrement d'items/blocks, events, networking, etc.), crée les abstractions Architectury nécessaires dans `common` et implémente-les dans `fabric`/`neoforge`.

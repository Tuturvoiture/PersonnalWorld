# Historique projet

Mémoire durable pour les humains et les agents Cursor — **indépendante** de l’historique de chat.

| Dossier / fichier | Rôle |
|-------------------|------|
| [`bdd/`](bdd/) | **BDD agent** — état, carte fichiers, décisions (lire avant de chercher) |
| [`prompts/`](prompts/) | Journal **par conversation** : un fichier, incrémenté à chaque prompt |
| [`sessions/`](sessions/) | Résumés de **livraisons** fonctionnelles (décisions, dettes) |
| [`sessions/INDEX.md`](sessions/INDEX.md) | Table d’entrée livraisons — lire avant un correctif (après la BDD) |
| [`audits/`](audits/) | Audits ponctuels (canvas, etc.) |
| [`../kit-nouveau-projet.md`](../kit-nouveau-projet.md) | Kit process (instance PW, paramètres remplis) |
| [`../HORS_SCOPE.md`](../HORS_SCOPE.md) | Ce que le projet n’est pas |
| [`../COMMANDS.md`](../COMMANDS.md) | Commandes canoniques (run / build) |
| [`../CHANGELOG_WIP.md`](../CHANGELOG_WIP.md) | Changements joueur non publiés |
| [`../CHANGELOG.md`](../CHANGELOG.md) | Releases archivées |
| [`../../builds/`](../../builds/) | Archive durable par `mod.version` (notes + META ; jars locaux) |

Ne pas y coller de secrets, chemins personnels sensibles, ni transcripts de chat complets.

# Definition of Done

Une livraison n’est **finie** que si :

- [ ] Comportement constaté en jeu (pas seulement « le code compile »)
- [ ] Version incrémentée dans `gradle.properties` → `mod.version` uniquement
- [ ] 1–3 bullets WIP (effet joueur)
- [ ] Entrée session (+ index)
- [ ] BDD à jour si un fait réutilisable a changé
- [ ] `docs/CAPABILITIES.md` si le produit a gagné/perdu un comportement
- [ ] Aucun secret, chemin perso, transcript

**Hors DoD :** refactor cosmétique, logs debug temporaires, bump « pour plus tard », docs process sans changement en jeu.

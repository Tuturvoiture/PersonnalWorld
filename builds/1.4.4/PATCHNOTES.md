## Changements

- Île active : changer d'île décharge les autres du propriétaire (éviction + unload), cooldown 2 min.
- Visiter / rejoindre une île non chargée est refusé ; le propriétaire doit l'activer d'abord.
- Login ou présence sur une île inactive / sans droit : renvoi à la position sauvegardée.
- Messages d'île plus clairs (désactivation ≠ rechargement).
- Spawn : bouton « Changer le spawn », message sous les pieds ; orientation 90° en coulisse.
- Tooltips FR/EN sur les boutons du carnet.
- Bouton Réserve visible « bientôt » (keep-loaded pas encore codé).
